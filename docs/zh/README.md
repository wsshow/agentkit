# AgentKit 文档

[English index](../README.md) · [项目 README](../../README_zh.md)

文档按照应用真正要解决的问题组织。无需启用所有子系统：先掌握运行时，再只加入当前 Agent 所需的能力。

## 推荐阅读路径

第一次创建 Agent：

1. 先运行根目录的[五分钟示例](../../README_zh.md#五分钟上手)。
2. 通过[运行时与事件](runtime.md)理解运行方法和事件生命周期。
3. 使用[测试](testing.md)让行为可重复验证。

构建生产级助手：

1. 加入[会话与持久化](persistence.md)。
2. 需要服务多个会话时使用[多会话管理](sessions.md)。
3. 在对话变长前加入[上下文管理](context.md)。
4. 检查[工具管理](tools.md)，尤其是超时与大型结果处理。

运行数小时或数天的工作：

1. 先完成生产级助手的基础配置。
2. 使用[持久化目标](goals.md)获得重启和重连语义。
3. 只在任务确实需要时加入 [MCP](mcp.md) 或[技能](skills.md)。

协调多个专业 Agent：

1. 通过[子智能体](subagents.md)声明有界且上下文隔离的专家。
2. 只给每个专家配置它确实需要的工具和 MCP 服务。
3. 工作需要跨步骤边界恢复时，再组合[持久化目标](goals.md)。

| 指南 | 内容 |
| --- | --- |
| [运行时与事件](runtime.md) | `Ask`、事件流、生命周期、请求值、HITL、队列、多模态输入 |
| [会话与持久化](persistence.md) | 会话恢复/保存、检查点、存储、并发控制、保留策略 |
| [多会话管理](sessions.md) | 创建、重连、所有者隔离、分页、归档、分支与 Agent 生命周期 |
| [持久化目标](goals.md) | `/goal` 式循环、异步执行、重连、恢复、租约、幂等性 |

| [上下文管理](context.md) | 完整历史与模型上下文、自动压缩、与结果压缩的执行顺序 |

可以直接运行的程序位于 [examples 目录](../../examples/)。公共 API 的逐项说明也可查阅 [Go 包文档](https://pkg.go.dev/github.com/wsshow/agentkit)。

## 文档约定

- 所有示例都会传入非空 `context.Context`；尚不确定生命周期时使用 `context.TODO()`。
- 写成 `&agentkit.SomeConfig{}` 的零值可选配置表示它具备刻意设计的安全默认值。
- “持久化”表示状态会写入所配置的存储，不表示进程停止后仍能在没有 worker 或 supervisor 的情况下继续执行。
- 文件存储面向本地单进程。多副本所有权需要基于数据库事务实现。
