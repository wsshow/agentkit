# Security Policy

## Supported versions

Security fixes are applied to the latest released version of AgentKit. Please upgrade to the newest release before reporting a problem that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's [private vulnerability reporting](https://github.com/wsshow/agentkit/security/advisories/new) and include:

- the affected AgentKit version or commit;
- the impact and realistic attack scenario;
- minimal reproduction steps or a proof of concept;
- any known workaround or suggested fix.

Please avoid accessing data that is not yours, degrading services, or disclosing the issue before a fix is available. The maintainer will coordinate validation, remediation, release, and disclosure through the private advisory.

For ordinary bugs without a security impact, use the [public issue tracker](https://github.com/wsshow/agentkit/issues) instead.
